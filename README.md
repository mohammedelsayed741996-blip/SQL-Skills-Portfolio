# SQL Learning & Skills Portfolio 🚀

Welcome to my SQL repository! This repository documents my continuous journey in mastering SQL, starting from beginner concepts up to advanced data analysis, database design, and optimization.

## 📂 Repository Structure

- **beginner-level/**
  - `01_database_setup.sql`: Database creation, schema definition (`customers` and `orders` tables), and sample data insertion (T-SQL).
  - `02_select_statments.sql`: Comprehensive queries covering `SELECT`, filtering with `WHERE`, sorting with `ORDER BY`, aggregations with `GROUP BY` & `HAVING`, `DISTINCT`, and row limitations.
